3. ID3 Algorithm — Concept & Core Formulas

ID3 (Iterative Dichotomiser 3) builds a decision tree by greedily choosing, at every node, the attribute that produces the purest possible split, measured using Entropy and Information Gain. It only works with categorical features and always creates one branch per attribute value (multi-way splits).

3.1 Entropy — measuring impurity/disorder

H(S) = − Σ pi · log2(pi)
where pi = proportion of class i in set S

Objective: Quantify how mixed/impure a set of examples is. Entropy = 0 means perfectly pure (all one class); Entropy = 1 (for 2 classes) means maximum disorder (50/50 split).

Role: Entropy is the base quantity used to measure impurity before and after a split, so we can measure how much a split helps.

3.2 Information Gain — choosing the best attribute

IG(S, A) = H(S) − Σv∈A ( |Sv| / |S| ) · H(Sv)
where Sv = subset of S where attribute A = v

Objective: Measure the reduction in entropy achieved by splitting on attribute A.

Role: ID3 computes IG for every candidate attribute at a node and picks the attribute with the highest Information Gain as the splitting attribute.

3.3 Step-by-Step Working of ID3 (using Dataset A)

Step 1 — Compute root entropy H(S)
Class counts: Yes = 6, No = 4, Total = 10 → p(Yes)=0.6, p(No)=0.4
H(S) = −(0.6 × log₂0.6 + 0.4 × log₂0.4) = −(0.6 × −0.737 + 0.4 × −1.322) = −(−0.442 − 0.529) = 0.971
Step 2 — Split on attribute "Wind" and compute conditional entropies
Wind = Weak → 7 rows (5 Yes, 2 No); Wind = Strong → 3 rows (1 Yes, 2 No)
H(Weak) = −(5/7·log₂(5/7) + 2/7·log₂(2/7)) = 0.863 H(Strong) = −(1/3·log₂(1/3) + 2/3·log₂(2/3)) = 0.918
Step 3 — Compute weighted entropy after split
H(S,Wind) = (7/10)×0.863 + (3/10)×0.918 = 0.604 + 0.275 = 0.879
Step 4 — Compute Information Gain for "Wind"
IG(S, Wind) = H(S) − H(S,Wind) = 0.971 − 0.879 = 0.092
Fig 2. Splitting on "Wind" reduces weighted entropy from 0.971 to 0.879 → Information Gain = 0.092.

4. ID3 — Building the Full Tree

Step 5 — Repeat Step 2–4 for every other attribute
Compute IG(S, Outlook), IG(S, Temperature), IG(S, Humidity) the same way as Wind. Suppose the results are: Outlook = 0.246, Humidity = 0.151, Temperature = 0.029, Wind = 0.092.
Step 6 — Select the attribute with maximum Information Gain
"Outlook" has the highest IG → it becomes the root node of the tree.
Step 7 — Split dataset by root attribute's values
Outlook = Sunny (rows 1,2,8,9) → Outlook = Overcast (rows 3,7) → Outlook = Rain (rows 4,5,6,10) Each branch creates a new (smaller) subset of data.
Step 8 — Check stopping conditions on each branch
• If all rows in a subset have the same class → make it a leaf node (e.g. Overcast → all "Yes", pure, becomes leaf directly).
• Otherwise, recursively repeat Steps 1–7 on that subset using the remaining attributes.
Step 9 — Recursion stops when: (a) all examples belong to one class, (b) no attributes remain, or (c) subset is empty (assign majority class).
Step 10 — Final Tree
The completed tree is a set of nested if/else rules built purely from Information Gain decisions — used directly for predicting new samples by traversing branch-by-branch.
Fig 3. Complete ID3 decision tree grown on Dataset A — every leaf here is already 100% pure.

4.1 Objective & Role of ID3 (Summary)

Objective of ID3: Greedily construct the tree that reduces entropy (uncertainty about the class label) the fastest at every step, producing a compact, human-readable rule set.

Role in ML pipeline: ID3 is the foundational classification-tree algorithm; it only handles categorical features/multi-way splits and has no built-in pruning, which limits it to simple, mostly categorical datasets — but it directly inspired CART and modern tree ensembles.

4.2 Limitations of ID3 (why CART was introduced)

  • Cannot handle continuous numeric attributes directly.
  • No built-in pruning → prone to overfitting.
  • Biased toward attributes with many distinct values.
  • Only supports classification, not regression.

5. CART Algorithm — Concept & Core Formulas

CART (Classification And Regression Trees) improves on ID3 by supporting both classification and regression, always producing binary splits (yes/no on a threshold), and using different impurity measures: Gini Impurity for classification and Variance Reduction for regression.

5.1 Gini Impurity — for Classification

Gini(S) = 1 − Σ pi2

Objective: Measure the probability of misclassifying a randomly chosen element if it were labeled randomly according to the class distribution in S. Lower Gini = purer node.

Role: CART evaluates every possible binary split and chooses the one that gives the largest reduction in weighted Gini impurity.

5.2 Step-by-Step — Gini Calculation (Dataset A, split on Wind)

Step 1 — Root Gini
Gini(S) = 1 − (0.6² + 0.4²) = 1 − (0.36 + 0.16) = 0.48
Step 2 — Gini of each child node (Wind = Weak / Strong)
Gini(Weak) = 1 − ((5/7)² + (2/7)²) = 1 − 0.592 = 0.408 Gini(Strong) = 1 − ((1/3)² + (2/3)²) = 1 − 0.556 = 0.444
Step 3 — Weighted Gini after split
Gini(S,Wind) = (7/10)×0.408 + (3/10)×0.444 = 0.286 + 0.133 = 0.419
Step 4 — Gini Gain (reduction in impurity)
ΔGini = 0.48 − 0.419 = 0.061
CART repeats this for every attribute/threshold and picks the split with the highest ΔGini.
Fig 4. Binary CART split on "Wind" — weighted Gini drops from 0.48 to 0.419 → Gini Gain = 0.061.

5.3 Variance Reduction — for Regression

Var(S) = (1/n) · Σ (yi − ȳ)2
ΔVar = Var(S) − [ (|SL|/|S|)·Var(SL) + (|SR|/|S|)·Var(SR) ]

Objective: Measure spread of target values around their mean; a good split should make each child's values cluster tightly around its own mean.

Role: CART regression trees select the split (feature + threshold) that maximizes ΔVar — equivalent to minimizing the Sum of Squared Errors (SSE) after the split.

6. CART Regression — Full Worked Example (Dataset B)

Step 1 — Compute overall variance of Price
Mean Price = 267. Sum of squared deviations = 86,610.
Var(S) = 86610 / 10 = 8661
Step 2 — Try candidate split: LocationScore ≥ 7 vs < 7
Left (≥7): rows 1,4,6,8,10 → Prices {220,400,340,430,300}, mean = 338
Right (<7): rows 2,3,5,7,9 → Prices {250,150,180,240,160}, mean = 196
Step 3 — Compute variance of each child
Var(Left) = 27680 / 5 = 5536 Var(Right) = 8520 / 5 = 1704
Step 4 — Weighted variance after split
Var(S,split) = 0.5×5536 + 0.5×1704 = 2768 + 852 = 3620
Step 5 — Variance Reduction (split quality)
ΔVar = 8661 − 3620 = 5041
This large reduction means "LocationScore ≥ 7" is a strong candidate split. CART repeats this test for every feature and every possible threshold, keeping the split with maximum ΔVar as the root node.
Step 6 — Recurse
Apply Steps 1–5 separately inside the Left and Right subsets (using remaining thresholds/features) until a stopping rule is met (e.g. minimum samples per leaf, or maximum tree depth).
Step 7 — Leaf prediction
Each leaf stores the mean of the target values that fall into it; new samples are predicted by traversing the tree to a leaf and returning that mean.
Fig 5. CART regression split on Dataset B — variance drops from 8661 to a weighted 3620 → Variance Reduction = 5041.

7. Random Forest — Concept & Core Formulas

Random Forest is an ensemble of many CART-style decision trees, each trained on a random subset of data and features, whose predictions are combined (voted/averaged) to reduce overfitting and variance compared to a single tree.

7.1 Bootstrap Aggregation (Bagging)

Di = Bootstrap_Sample(D),   i = 1 … N

Objective: Create N different training sets by sampling rows from D with replacement, so each tree sees a slightly different version of the data.

Role: Introduces diversity between trees, which is the key ingredient that makes the ensemble more robust than any single tree.

7.2 Random Feature Selection at Each Split

m = √p   (classification)  |  m = p/3   (regression)
where p = total number of features, m = features randomly considered per split

Objective: At every split, only a random subset of m features (not all p) is considered.

Role: Prevents all trees from always splitting on the same dominant feature, which further de-correlates the trees.

7.3 Aggregation Formulas

ŷclassification = mode { T1(x), T2(x), … , TN(x) }
ŷregression = (1/N) · Σ Ti(x)

Objective: Combine all N trees' individual predictions into one final answer — majority vote for classification (Dataset A: PlayGolf), simple average for regression (Dataset B: Price).

Role: Averaging/voting cancels out individual trees' errors (variance), which is the core reason Random Forest generalizes better than a single ID3 or CART tree.

Fig 6. Random Forest bagging pipeline — N bootstrap samples train N independent CART trees, whose outputs are combined by majority vote (classification) or averaging (regression).

7.4 Step-by-Step Working of Random Forest

Step 1 — From the original dataset (e.g. 10-row Dataset A or B), create N bootstrap samples (e.g. N = 100), each of size 10, drawn with replacement.
Step 2 — For each bootstrap sample, grow a full CART tree using Gini (classification) or Variance Reduction (regression) as in pages 4–5.
Step 3 — At every node split inside each tree, randomly restrict candidate features to m = √p (Dataset A: p=4 → m=2) or m = p/3 (Dataset B: p=4 → m≈1–2).
Step 4 — Grow each tree to full depth (or a max-depth limit) with no pruning — individual trees are allowed to overfit slightly.
Step 5 — To predict a new sample x: pass it through all N trees to get N individual predictions.
Step 6 — Aggregate: take the majority class vote (classification) or the mean (regression) as the final Random Forest prediction.
Step 7 (optional) — Rows not included in a tree's bootstrap sample ("out-of-bag" rows) can be used to estimate the model's OOB error without a separate test set.

7.5 Objective & Role of Random Forest

Objective: Reduce the high variance of individual decision trees (ID3/CART) by averaging many de-correlated trees, improving accuracy and stability.

Role in ML pipeline: Serves as a strong, low-maintenance baseline model for both classification (Dataset A → PlayGolf) and regression (Dataset B → Price), typically outperforming a single decision tree while remaining reasonably interpretable via feature importance scores.
